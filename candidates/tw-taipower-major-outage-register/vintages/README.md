# Pinned vintages of the Taipower major-outage register

Each file here is a byte-exact anonymous capture of the data.gov.tw quality-mirror
of dataset 122741 (台灣電力公司配電系統重大事故停電速報案件記錄 - Taipower
distribution-system major outage flash-report case records), named
<capture-date>__<sha256-16>.csv and produced by scripts/standing-capture.py.

Why these bytes are pinned: the live file is a single-year replacement file -
when the publisher replaces the 2024 vintage with a later year, the 2024 events
are gone from the source (the only other copies are Internet Archive captures;
CDX showed exactly one 2024-content capture, 20260929233634). The candidate
tw-taipower-major-outage-register reopens for ready-review when >= 4 distinct
yearly vintages exist with per-vintage corruption checks passing; see
../standing-captures.json (the capture ledger) and the candidate record.
