jma-typhoon-rapid-intensification

dropped · JP 11:50 UTC

The question

what a model is asked to predict

Formulation considered: from a tropical cyclone's JMA best-track state and history through the 6-hourly analysis time t (position, central pressure, maximum sustained wind, storm grade, past-24h track), predict whether the cyclone undergoes rapid intensification (RI) in the following 24 hours (Vmax increase >= 30 kt). NOT taken forward: the same prediction question already ships in ML-ready, split, scored form elsewhere (TCRISI: satellite-image + best-track RI benchmark with official train/validation/test splits and a benchmark repository; TCBench: IBTrACS-based TC track/intensity benchmark with year-based splits), so a best-track-only RI task is a mirror of an existing usable task, not a contribution.

What you predict

target definition

Binary RI: Vmax(t+24h) - Vmax(t) >= 30 kt. Unit/reference-frame caveat recorded before the rejection was reached: the 30 kt/24 h RI standard is defined on 1-minute sustained winds (Kaplan & DeMaria convention), while JMA best-track winds are 10-minute sustained, so a JMA-units task would need an explicit threshold decision and a known-event fixture; this question is moot because the task is a mirror.

When the prediction is made

the information cut-off

For the rejected formulation only: the 6-hourly best-track analysis instant t (all track parameters through t knowable); the label is the change in the same storm's final-analysis Vmax over the following 24 h, so rows at t+24h.. are label source. Best track is a post-season final analysis, which is the documented grain of the source, not a leakage defect.
