The question

what a model is asked to predict

Hypothetical task this source supports (not taken forward): for a recall notice published on the Government of Canada Recalls and Safety Alerts system, predict its hazard classification (food Class 1-3, medical device Type I-III) from features available before classification.

What you predict

target definition

'Recall class' column of the open-data CSV (measured values: Class 1/2/3 for CFIA food recalls, Type I/II/III for medical devices, empty for Transport Canada vehicle recalls). The label is assigned by the recalling organization under a documented risk-classification process - so the label itself is fine; the task is not.

When the prediction is made

the information cut-off

Would have to be the moment the recall notice is published; the notice row carries the class in the same record, and 'Last updated' is a revision date not a first-publication date (measured: some rows carry an empty value), so timing a pre-classification instant from this product alone is not cleanly possible.
