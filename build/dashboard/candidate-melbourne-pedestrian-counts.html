The question

what a model is asked to predict

For a City of Melbourne pedestrian sensor, will the count in a given hour exceed a high-traffic threshold relative to that sensor's own distribution?

What you predict

target definition

Binary: pedestriancount for the hour exceeds a per-sensor quantile threshold frozen from the training window. The threshold is not yet chosen; the per-sensor distribution must be measured first.

When the prediction is made

the information cut-off

Shortly before the hour being predicted, using only prior hours, calendar position and sensor identity. The same hour's direction splits are the label source and must not be features.
